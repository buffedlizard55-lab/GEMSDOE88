How to reproduce

  1. python -m venv .venv && .venv/bin/pip install -r requirements.txt
  2. .venv/bin/python scripts/restore_inputs.py (automated GitHub sparse checkout, pinned SHA; about 419 MB feature raster).
  3. .venv/bin/python scripts/run_experiment.py (one predeclared test, writes receipts and research artifact; fails closed rather than overwriting).
  4. .venv/bin/python scripts/validate_release.py --require-submit (must return 2 on this negative file).

No tokens or cookies are needed to restore the owner mirror. DrivenData login is needed to retrieve organizer-authenticated downloads and submit. Large private inputs are excluded from Git.
