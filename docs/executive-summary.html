Procedure

How to submit to the DrivenData competition (when a candidate is cleared)

  1. Go to DrivenData competition 306 (DOE GEMS Prize) and sign in.
  2. Click Submit → New submission.
  3. File to submit: choose the single-band GeoTIFF (.tif) or a .zip containing exactly one GeoTIFF. It must match the submission format's CRS (EPSG:32611), shape (3730×3292), and geotransform (100, 0, 243350, 0, -100, 4508550).
  4. Values must be in [0, 1] with no NaN/Inf — the portal rejects anything outside this range ("Predicted values must be in range [0, 1]").
  5. Name: enter a unique submission name (e.g. GEMSDOE88-RELAY-DILATIONAL-UNIQUE, ≤140 chars).
  6. Note: enter a short comment to tell submissions apart (e.g. clustering with k=25), ≤140 chars.
  7. Click Submit. A submission-page receipt is the only ORGANIZER-CONFIRMED score.
