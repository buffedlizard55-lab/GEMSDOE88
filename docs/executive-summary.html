Step-by-step competition submission guide

Exactly how to submit (only when the gate says OK TO SUBMIT)

Official facts: submissions are single-band GeoTIFFs at 100 m for the whole GeoDAWN area (NLR rules §3.2); you may submit up to three per week but the website’s displayed limit prevails (DrivenData staff); you must select exactly one final submission for both prize rounds before the deadline, without private-set knowledge (§3.4, §3.5, §3.6.2). Competition end: 2026-12-03 23:59 UTC.

  1. Check the decision

    Open this page or registry/gate_verdict.json. If it says NOT OK TO SUBMIT, stop. To recompute everything from bytes: python scripts/restore_inputs.py && python scripts/restore_siblings.py && python scripts/validate_release.py --full --require-submit (exit code 0 only when every gate passes; without --full it re-verifies the committed receipts and the file itself).

  2. Open the portal

    Log in at the competition page, press Submit in the sidebar, then Make new submission (“How to compete”, steps 5–6).

  3. Upload one file

    Upload the .tif or the .zip (exactly one TIFF inside). Do not rename the TIFF inside the ZIP.

  4. Paste a unique name and the short note

    Use the copy buttons above (≤140 characters each). Never reuse a name.

  5. Record the receipt

    Copy the portal’s score and date into ledger/submissions.csv as ORGANIZER-CONFIRMED. Until then every number in this repository is a holdout number or an owner-reported claim.

  6. Final selection (human)

    Before the deadline pick the single submission to be scored in both rounds; AI-use disclosure is required in the narrative (rules §3.2; see AI_USE.md).

Preventing the [0, 1] portal error

The portal message “Predicted values must be in range [0, 1]” has an unproven cause (organizer code is not public). Three suspects are removed together: (1) no NaN/Inf anywhere (a NaN fails (a≥0)&(a≤1) when nodata is undeclared), (2) values asserted in [0, 1] before a no-op clip, (3) the layout mirrors the official sample (LZW, 1-row strips, classic TIFF, float32); earlier files were tiled + DEFLATE. The gate emulates both common range checks and decodes the file with two independent readers. If the portal still rejects it, the error text and file hash are the data needed: record them as a new irregularity.
