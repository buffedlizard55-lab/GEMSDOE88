Procedure for a future green candidate only

Exact DrivenData submission steps

  1. Require machine approval

    Open that candidate's run card. Require ok_to_submit: true, every scientific/uniqueness/format gate true, a unique name and note of at most 140 characters, and validate_release.py --require-submit exit 0. Any failure means stop.

  2. Verify the downloaded bytes

    Compute SHA-256 and require an exact match to the run card. A changed filename or hash alone is not evidence of uniqueness. The TIFF must be single-band and match the organizer sample's CRS, shape, and geotransform.

  3. Upload exactly one artifact

    Sign in to the DrivenData submissions page. Choose either the approved .tif or its ZIP containing exactly one TIFF. Never select a file whose name contains DO-NOT-SUBMIT.

  4. Paste the approved name and note

    Use the exact fields from the green run card. Confirm the note is no more than 140 characters and the portal's current weekly quota allows the slot.

  5. Submit once and archive the receipt

    Only a value copied from the resulting portal receipt may be called ORGANIZER-CONFIRMED. HOLDOUT-DTI and model projections are not leaderboard scores.
