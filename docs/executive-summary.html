If a file is promoted, do this

  1. Open drivendata.org/competitions/306/competition-doe-gems/submissions/ and sign in.
  2. Choose file: the .tif or the .zip (exactly one TIFF inside, no folder). Drag-and-drop works.
  3. Paste note: copy the promoted run card’s submission_note verbatim (≤140 chars). The portal has no “name” field — name is for your ledger only.
  4. Create: click Create once. Do not double-click. The portal validates CRS/shape/transform and [0,1] range server-side.
  5. Save receipt: the portal shows ORGANIZER-CONFIRMED public DTI. Screenshot it and append to ledger/submissions.csv (never relabel HOLDOUT-DTI).
