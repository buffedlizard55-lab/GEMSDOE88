Exact portal procedure

Steps for a later, fully gate-cleared candidate

  1. Wait for automated project approval

    Require a positive paired spatial-blocked HOLDOUT-DTI improvement with a 95% interval above zero; all individual feature canaries at or below 0.90; both surface and final-dot uniqueness within the authorized limits; and a successful saved-byte validator. A unique filename alone does not count.

  2. Download only the file identified by that approved run card

    Use its direct single-band .tif, or the provided ZIP containing exactly one GeoTIFF. Verify the SHA-256 against the run card before uploading. The current artifact on this page is explicitly excluded.

  3. Open the official submission page and select the file

    Sign in to the team account, open DrivenData GEMS submissions, choose New submission, and upload the one TIFF or one-TIFF ZIP. It must match EPSG:32611, the provided 100 m grid, exact bounds/transform, one float32 band and prediction values in [0,1].

  4. Enter the unique name and short note

    Copy the submission name and note from the approved candidate's run card. Keep the note under 140 characters, describe the model, and avoid presenting holdout metrics as organizer scores.

  5. Submit only after selector authorization

    The project never chooses a weekly submission slot. Confirm that a separate portfolio selector has chosen the candidate and that the live submission page permits it; the website's actual cap takes precedence over any remembered cap.

  6. Archive the organizer receipt

    Save the receipt verbatim to the evidence ledger. Only then label its result ORGANIZER-CONFIRMED. A local HOLDOUT-DTI, model projection, proxy, or user-reported sibling score is not an organizer receipt.
