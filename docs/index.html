What was actually measured

Geophysical hypothesis, not a leaderboard claim

The competition targets previously unrecorded faults indicative of geothermal resources — not the direct detection of geothermal vents. A magnetic/gravity boundary is not by itself a fault.

Physical signal

At a buried structural discontinuity, magnetization and density contrasts can each create a potential-field edge. We tested locally aligned signed gradients of reduced-to-pole magnetics and isostatic gravity, conditional on depth to base surface, using only three competition layers. A lithologic contact or survey seam can mimic this co-edge; blocked evaluation is necessary.

Why the group-reported H33 result is plausible

The user’s 0.2778 claim is not organizer-confirmed here. Reading the pinned H33 TIFF pixel-by-pixel proves something narrower and more useful: its 37,654 positive pixels are an exact subset of the earlier D2.8 raster’s 44,090. Exactly 6,436 pixels were removed — all pixels within 2 grid cells of the mapped catalogue; none of the more distant dots changed.

The official distance-weighted metric rewards truth coverage but charges for unmatched prediction mass. Deleting near-catalogue dots could reduce false-positive cost while retaining off-catalogue coverage. The hidden truth and a submission-page receipt are unavailable, so this is a mechanistic hypothesis, not a causal attribution or proof of that score. Read the pixel audit →

The budget effect, without shortcuts

For binary predictions, write T for weighted truth coverage, M for prediction-to-truth proximity credit, S for dot count, and G for true pixels:

DTI = T / [0.2 × (T + S − M) + 0.8 × |G|]

Thinning can improve this fraction if the removed pixels cost more than the coverage they supply. It cannot guarantee a gain: without hidden G, neither T nor M is observed. A published sibling explanation uses a different marginal threshold; we flag and re-derive it rather than adopt it.
