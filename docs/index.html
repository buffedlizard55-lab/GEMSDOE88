H33 forensic explanation

Why user-reported H33 reached 0.2778

The 0.2778 value remains a user report, not ORGANIZER-CONFIRMED, because no authenticated portal receipt exists in this repository. H33 (37,654 dots) is a strict pure-subtraction lineage: H19-5 ⊃ D1.5 ⊃ D2.8 ⊃ SOLO-D2.8 ⊃ H33. Every removed dot after D2.8 lay within 2 px of the mapped catalogue; removing pure false positives raises DTI (denominator falls by exactly 0.2 per removed dot). Dots are spaced ~one kernel radius apart (median 3.0 px NN spacing), which the max-vs-sum DTI structure rewards. Two lineage steps imply a public positive pool |G| ≈ 13–15 k px and mean credit per dot ≈ 0.14 vs break-even 0.0556 at DTI 0.2778 — roughly 2.6× above break-even.

Can a higher result be supported?

Not by GEO-THERMAL-88 or any file in this repo. No raster here clears every gate. The live leaderboard #50 is 0.2818 and the top is 0.4413, so even H33's owner-reported 0.2778 would sit below rank 50. Beating it requires dots with above-break-even credit hitting truth the leaderboard rewards — an open research question. The evidence supports continued research, not spending a weekly slot on this file.
