### 1.2 Why `H33` (`h33-h33-2-b2-...-zeros`) Outperformed Earlier `GEMSDOE` Submissions: DTI Algebra & Measured Lineage Geometry

The competition Distance-Weighted Tversky Index (`vendor/gems57/metric.py`, transcribed from the problem specification) is:

$$\mathrm{DTI}(P, G) = \frac{\mathrm{TP}_w}{\mathrm{TP}_w + \alpha\,\mathrm{FP}_w + \beta\,\mathrm{FN}_w}, \qquad \alpha = 0.2,\quad \beta = 0.8,\quad k(d) = \max\!\left(0,\,1 - \frac{d}{300\text{ m}}\right).$$

$$\text{H33 } (37{,}654\text{ dots}) \;\subset\; \text{H27-4 } (40{,}199) \;\subset\; \text{D2.8 } (44{,}090) \;\subset\; \text{SOLO/H19-5 } (\sim 121{,}400).$$

Three exact mathematical mechanisms explain why the supplied `USER-REPORTED` progression climbs monotonically along this chain (`~0.1922 -> 0.2477 -> 0.2600 -> 0.2738 -> 0.2778`) **without** invoking unverified claims of superior deep-geothermal physics:

1. **Submodular `300 m` Kernel Saturation (Spacing Thinning `H19-5 -> D2.8`):** Because `TP_w` evaluates $\max_{p \in P} k(\|g - p\|)$ at each hidden truth pixel $g$ while $\mathrm{FP}_w$ sums $(1 - \max_{g \in G} k(\|p - g\|))$ **additively over every emitted dot $p$**, adjacent dots separated by `100–200 m` (`1–2 px`) contribute almost zero marginal $\Delta\mathrm{TP}_w$ (their `300 m` cones overlap heavily) while paying full marginal $0.2\,\Delta\mathrm{FP}_w$ whenever no hidden fault lies within `300 m`. Thinning `~121k` contiguous ridge pixels to `44,090` spaced dots (`NN spacing ~2.8–3.0 px`) preserves nearly the same `300 m` tube envelope while cutting $\mathrm{FP}_w$ by nearly two-thirds.
2. **Near-Catalogue Collar Pruning (`D2.8 / H27-4 -> H33`, `-6,436` / `-2,545` dots at $d_{\mathrm{cat}} \le 2\text{ px}$):** Pinned byte forensics confirm that **100% of the `6,436` dots removed between `D2.8` (`44,090`) and `H33` (`37,654`) lie within `<= 2 px` (`200 m`) of the public mapped fault catalogue** (`existing_faults.tif > 0`). Because mapped catalogue pixels are masked/excluded from new-fault credit, dots placed `100–200 m` alongside already-mapped strands rarely capture genuinely *new* unmapped fault segments yet incur systematic false-positive penalties where no parallel unmapped strand exists.
3. **Exterior `zeros` Encoding (`-zeros` vs `-nan`):** Replacing exterior `NaN` outside the valid study footprint with finite `0.0` (`nodata=None`) avoids the portal's whole-array `0 <= arr <= 1` validator rejection (`"Predicted values must be in range [0, 1]"`), allowing the raster to be scored rather than rejected at upload. **Crucial scientific caveat:** nested geometry and user-reported figures prove *what* changed in pixel space, not causal performance on hidden organizer labels, because removing predictions can also reduce $\mathrm{TP}_w$ where hidden splays abut mapped faults.
