# `H88-MRR` Session — Ranked Untried Geological Hypotheses (`2026-10-24`)

## Scope and evidence boundary

This session follows the prior handoff in `research/next-steps.md`: test the previously unrun **MRR-88 intra-magnetic residual lane** for blind faults beneath volcanic/alluvial cover. The five candidates below were checked against the repository source and experiment ledger before implementation. None of the named transforms appears as a completed `(parent, axis, value)` row in `ledger/submissions.csv`, and `grep` finds no implemented blockwise vertical-to-regional magnetic residual. Existing `H88-ADHR` includes raw magnetic derivatives and a Laplacian demagnetization feature, but **not** blockwise nuisance regression, polarity residuals, depth-normalized phase, or connected residual-corridor persistence.

All candidates use only the already cached organizer-provided 19-band stack; no new external data is required. Band identities are pinned by on-disk tags and by the organizer reference notebook at commit [`aebe92f7c8a990f0e3443451b7a825d9afd6336b`](https://github.com/drivendataorg/gems-prize-reference-solution/commit/aebe92f7c8a990f0e3443451b7a825d9afd6336b). The owner mirror's legal/organizer-byte identity remains unverified (`IR-88-02`, `IR-88-17`).

## Frozen decision rule

1. Implement **only Rank 1** in this session (`1 / 3` experiment budget; the incumbent is a control, not a new experiment).
2. Audit each of its four channels alone on the Seed-20 whole-component holdout. Symmetric ROC AUC `> 0.90` is an automatic leakage stop.
3. Evaluate incumbent `H88-ADHR` and `H88-MRR-BPR` on the same 8 buffered whole-component folds using unmodified `vendor/gems57/evaluate_holdout.py` (`gems57-pooled-hide-v2`, alpha `0.2`, beta `0.8`, `300 m` triangle, `20 km` paired block bootstrap).
4. Promotion requires candidate pooled `HOLDOUT-DTI` to exceed the recomputed incumbent. A paired `95% CI` crossing zero is explicitly inconclusive even if the point estimate is higher.
5. Generate and validate the candidate GeoTIFF regardless of sign because negative results are deliverables; however, label it `DO-NOT-SUBMIT` unless every gate clears.
6. Apply the literal uniqueness gate to **every** indexed raster. The already measured all-positive `17GEMSDOE` witness implies every nonempty candidate has 3-pixel forward overlap `1.0`; therefore the expected literal verdict is `negative`. This is not silently exempted.
